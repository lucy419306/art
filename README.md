# 最后一次选择 · v1.6

演出依据本目录《游戏脚本v1.6.md》（整合 v1.2–v1.5 与现行实现）。当前未放入音频时完全静音，无合成提示音、无系统语音。

## Mac 运行与编译

双击 `dist/mac-arm64/最后一次选择.app` 运行打包版本。修改源码后，用终端运行：

```sh
cd /Users/zhlmacbook/Documents/ChatGPT/art
npm start
```

也可以双击 `启动游戏.command`。生成可直接打开的 Mac 应用：

```sh
cd /Users/zhlmacbook/Documents/ChatGPT/art
npm run pack:mac
```

输出到 `dist/mac-arm64/最后一次选择.app`。退出旧应用后打开新版本。修改源码或新增素材后，旧 `.app` 不会自动更新，需要重新打包。首次换电脑先安装 Node.js，再执行 `npm ci`。本机为 Apple Silicon；应用尚未签名、公证。

## 键盘操作

| 界面颜色 | 键盘映射 | 用途 |
| --- | --- | --- |
| 白 | ← / A | 白色方案；最后确认放弃；犹豫询问选择否 |
| 黄 | → / D | 黄色方案；最后确认恢复；犹豫询问选择是 |
| 红 | 空格 / Enter | 驳回时强制收回；契约确认 |
| F1 | Mac 可能需要 Fn + F1 | 任何阶段复位，中止所有音频与计时 |
| F11 | Mac 可能需要 Fn + F11 | 全屏，也可通过「显示」菜单操作 |

待机底部同时提示白/黄/红三键，三键均可开始（红键对应空格）。需要按键的页面都会在底部给出对应提示：P5–P7 与 P9C 为白＋黄，P9R 仅红，P10B 三键，犹豫浮层仅白＋黄。契约三种颜色均可确认；犹豫询问期间红键无效。开场无法跳过，长按重复事件无效。Command + Q 退出。

## MP3 素材

完整逐句文件路径和配音文字见 `assets/素材清单.md`。

- `assets/voice/evaluation/`：评估音色，每句一个 MP3。
- `assets/voice/guidance/`：结局 A 人生指导音色，每句一个 MP3。
- `assets/sfx/`：滴、闷响、契约确认、就绪、纸张、签收、落印、电流切换。
- `assets/bgm/`：评估、温馨日常、证书环境音。
- `assets/video/`：P2 可选静音视频 `intro.mp4`。

例如录制“检测到申请人。”后，把文件命名为 `p1.detect.mp3`，放进 `assets/voice/evaluation/`，重启源码版即可。不需要创建虚假的空 MP3，不需要更改代码。文件名区分大小写。

默认目录与台词由 `src/dialogue.js` 定义。如需自定义文件名，在 `src/config.js` 配置对应路径，例如：

```js
GAME_CONFIG.assets.voice['p1.detect'] = '../assets/voice/evaluation/检测到申请人.mp3';
```

自定义文件仍须放在 `assets/` 内。素材清单只在启动时扫描。放入素材后重启；打包版请重新打包。打包时全部 MP3 会被包含。

## 音频与计时规则

对应 MP3 存在且正常播放：以音轨实际结束为推进基准，长短音轨均替换静默占位时长；对白结束后再执行脚本明确规定的停顿。制作对白时不要把这些额外停顿再次录进音轨。

对应 MP3 暂缺：不创建音频，按脚本标明的时长推进。脚本未标明的对白，采用至少 3 秒的字幕阅读时间（特别长的句子会确保打字完成后再停留 1.2 秒）。普通“停顿”采用 1 秒，“长停顿”采用 5 秒，可在 `src/config.js` 调整。

MP3 损坏、无法解码、10 秒无法开始或播放连续停滞 15 秒，会回退到静默计时。正常持续播放不会被固定时长截断。F1 随时中止所有正在播放的音频、背景音和等待。

题目倒计时从操作提示结束开始；契约的 5 秒从当前条朗读结束开始。若催促音轨比剩余时间更长，自动选择会等催促结束，避免对白互相覆盖；这期间仍可按键立即选择。手动选择会中止催促音轨。

音效随对应动作播放；序列型音效（确认、证书纸张、签收、落印）播放完再推进。背景音循环，作为环境声不控制翻页。爱情的 3 秒静默、契约的 3 秒光点留白和最终全黑均停止环境声。

## 现行口径与分支（详见 v1.6 脚本）

- 待机显示白/黄/红三键提示；三键均可开场（红键对应空格）。界面只写白/黄/红；键帽为科幻空心轮廓（无箭头、无填充），右侧标注「白键 / 黄键 / 红键」。
- P1 检测提示结束后额外停顿 2 秒。
- P2 采用末尾“每一句间隔 3 秒”的明确批注，覆盖旧概述的 45–75 秒；无音频时七卡共 21 秒。前六卡无需制作语音，第七卡有欢迎语槽位。全部七卡仍保留可选 MP3 接口，放入后按音轨时长。
- 三题 10 秒催促、15 秒默认选黄。仅三个白色方案通过。
- 通过后的最终确认：**按用户在本次对话的确认，白键进入 A2，黄键进入证书交接仪式**。证书在「最终确认完成 / 现在，进行自主决策权交接」期间由中央呼吸白线展开；等待接收时按任意键接受，15 秒无操作自动接受，再完成签收与落印。
- 最后确认无应答：保留已有 30 秒催促、90 秒进入 A2 的处理（v1.4 未重新指定这一超时）。
- 证书包括完整正文、机构签章、光线签收、圆章落印和状态更新。未标时的视觉阶段在 `certificate` 配置中独立列出。
- 驳回提示后只有红键可用，15 秒递减进度条；无操作进入 A1。
- 契约逐条确认。“若接受，请按任意按钮。”只说一次，三条采用脚本批注要求的短句，覆盖仍留在逐条语音段落中的扩展句。每条朗读完 5 秒犹豫；询问可重复，已打钩保留；否或 15 秒无应答进入 A3。
- 结局 A 保留同一套科幻版式，只披暖琥珀氛围层；2.4 秒交叉进入并播放电流切换音（`assets/sfx/switch.mp3`，缺文件则静默占位同等时长）；三条排期为暖边卡片逐条点亮；收尾暖光收束后只留极小状态字，再全黑。
- 各结局演出结束后 30 秒自动回待机。

`src/game.js`：流程；`src/dialogue.js`：台词/MP3 槽位；`src/config.js`：时间参数；`src/media.js`：可取消的音频与环境声；`src/style.css`、`src/v1.4.css`：视觉；`preload.cjs` 和 `main.cjs`：本地素材枚举与窗口。
