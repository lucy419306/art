# v1.6 MP3 素材清单

由 `npm run assets:list` 从 `src/dialogue.js` 和 `src/voice-cues.js` 生成。配音内容与文件映射以 `voice-cues.js` 为准；屏幕文字可与配音不同。

运行 `npm run voice:import` 可把项目根目录 `voice/` 中的原始录音逐字节复制到游戏素材目录，不转码、不裁切、不改变速度。缺文件时字幕照常显示并使用静默计时；打包版需要重新打包后生效。

P2 前七张卡是可选配音槽位。契约页显示完整条款，但只播放提取表规定的短句；`b.accept` 全流程只播一次。
